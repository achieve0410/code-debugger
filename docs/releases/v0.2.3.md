# code-debugger v0.2.3

`v0.2.3` republishes the `v0.2.2` fail-closed fixes with corrected verification
wording. The immutable `v0.2.2` notes called two successful pre-release source
runs "Exact-main"; those runs verified the complete fix tree before its
version-only release commit, but their recorded SHA was not the final release
SHA. This release keeps immutable history intact and states that distinction
accurately.

## Included fixes

- Malformed frontend API helper files cannot contribute concrete HTTP URL
  symbols to healthy React or Vue files.
- Malformed Vue router files cannot emit inferred route topology.
- Malformed Nuxt page SFCs cannot emit file routes after component rejection.
- Rejected files remain explicit through deterministic `unsupported_syntax`
  diagnostics.

## Compatibility and security

The supported frameworks, strict `GraphSnapshotV2`, local-only HTTPS boundary,
source-context clipboard limits, and static/runtime evidence contracts are
unchanged. Unsupported, external, missing, and dynamic facts remain explicit
diagnostics or `Unresolved`.
